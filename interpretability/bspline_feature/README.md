# B 样条 KAN：跨轴承积分梯度归因

这组解释对应新训练的 **B 样条 KAN**，不是之前的 ChebyshevKAN。使用已完成的 15 折留一轴承实验（`seed=42`）：每一折取该折模型及其从未参与训练或验证的测试轴承，每条采集记录分别解释实际非负截断后的分钟预测。

使用 64 步中点积分梯度，以各折的训练特征均值为基线。先计算每只测试轴承内各特征的平均绝对归因，再对 15 只轴承等权平均；每个轴承由不同折训练出的模型解释。归因的分钟单位描述相对基线的模型输出变化，不是预测误差、寿命损失，也不能直接用于推断物理因果。

| 输入特征 | 平均绝对归因（分钟） | 在多少只轴承上位列前三 |
| --- | ---: | ---: |
| 标称转速 | 75.96 | 10/15 |
| 径向载荷 | 67.25 | 8/15 |
| 水平振动峰值 | 38.58 | 7/15 |
| 已运行时间 | 38.47 | 7/15 |
| 垂直 RMS | 30.70 | 3/15 |

`bspline_global_importance.png` 含全部 13 个输入；`global_feature_importance.csv`、`per_bearing_feature_importance.csv` 和 `metrics.json` 提供全部结果与单轴承排名。积分完整性误差是各轴承等权平均 **0.195 分钟**；相对平均绝对输出差 212.791 分钟约 **0.091%**，这是数值误差检查，不是解释物理真实性指标。

**重要限制：**数据的标称转速和载荷仅有三个固定配对，彼此强相关。当前归因结果不能可靠区分速度或载荷各自的影响；振动特征也可能相关，训练均值基线及沿均值到样本的插值可能对应不真实的特征组合。只有一个训练种子，15 个轴承是不同测试对象但共享 15 折的交叉训练数据，不能把它们当成 15 个独立研究。此分析检查了测试轴承，不能用这里的结果选特征后仍把这些轴承作为独立最终评价集。训练目标是距最后采集的分钟，不是精确失效时刻。
