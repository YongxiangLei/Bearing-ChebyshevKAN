# Paderborn 辅助故障分类模型：可解释性分析

此分析使用项目 `pu/outputs/model.pt` 已训练权重，不更新模型。PU 是独立轴承故障分类辅助任务，不是剩余寿命预测。独立留出的 6 个测试轴承各有 2 条记录、每条记录取 100 个不重叠的 1024 点窗，共 1200 窗。每窗减均值、除标准差后计算幅值 FFT，再用训练集参数标准化，完全沿用分类模型预处理。

积分梯度（IG）解释原始预测类与次高类的 logit 差，使用 64 个中点、标准化特征零向量（即训练集平均 FFT 特征）作基线。模型测试准确率只有 38.67%；解释反映模型依赖，不能保证故障判断正确。

- 归因完整性误差均值为 0.00956，平均目标输出差绝对值 2.32243，两者之比 0.412%；这只是数值积分的完整性检查。
- 每个窗口绝对归因最大的 52 个频点（513 维中的 10.14%）占绝对归因总量的平均 32.91%。
- 屏蔽这些频点时模型预测与原预测的一致率为 86.92%，随机屏蔽 52 维的 20 次均值为 95.31%；原始预测类与次高类的平均 logit 差分别下降 0.3055 和 0.0691。屏蔽后模型准确率从 38.67% 升至 44.58%，只是有错误预测改变，不能作为模型经过改进的证据。
- 在原始振动窗口加合成 AWGN 后，再执行相同预处理。5 次噪声随机抽样、固定原始预测/次高类别作为归因目标：20 dB 时前 52 频点平均 Jaccard 相似度 0.5052、预测一致率 97.12%；−4 dB 分别为 0.0801 和 20.07%。−4 dB 是强扰动且多数预测已改变，不能将低 Jaccard 直接归因于解释方法本身。
- 只统计预测类别未变的窗口，20 dB 下 Jaccard 均值为 0.5079，−4 dB 下为 0.1138。后一指标基于约 20.1% 未变窗口，存在选择偏差。

各轴承准确率分别为 K005 0%、K006 100%、KI07 95.5%、KI16 36.5%、KA06 0%、KA07 0%。每类仅 2 个轴承、单一工况，窗和噪声重复高度相关，不能据 1200 窗声称 1200 个独立实验。频谱遮蔽及 IG 插值可能不符合真实信号分布；频点归因是模型依赖，不是物理因果。

在项目根目录的 PowerShell 运行：

```powershell
$env:PYTHONNOUSERSITE = '1'
.\.venv\Scripts\python.exe .\interpretability\pu\eval_pu_ig.py
```

结果写至脚本同目录 `metrics.json`；`ig_test.npz` 保存逐窗归因、标签、轴承 ID、固定目标类别和标准化 FFT，供后续分析。默认从代码相对位置定位项目根目录，也可用 `--project-root` 指定；脚本需要已准备的 `data/PU/selected_mat` 和 `pu/outputs/model.pt`。重复运行会覆盖同名结果。五次噪声种子为 2026–2030，仅反映噪声抽样变化。
