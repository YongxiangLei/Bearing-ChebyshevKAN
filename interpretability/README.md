# CWRU 模型可解释性检查

## 分析对象和结论

本检查使用 CWRU 的噪声增强 ChebyshevKAN 权重 `cwru/exp/outputs/cwru_augmented/model.pt`。测试集是 0 hp 的 470 个干净窗口：每类原始记录最后 20%，512 点窗、50% 窗内重叠。模型和特征缩放均来自已有训练，没有为解释重新训练。

模型的特征归因能通过基本的数值完整性和遮蔽对照检查，但在较强噪声下的重要频点排序变化大；目前没有足够证据证明它学到的特征对应真实故障机理。窗口来自各类同一条原始记录，且相互重叠，不能当成独立轴承或独立实验。以下整体数字按窗口计算，正常类 189 窗，其他类各约 93–94 窗，并非类别宏平均。

## 特征归因

采用 64 步积分梯度（Integrated Gradients），解释原模型的预测类别相对次高类别的 logit 差。基线为训练集 FFT 特征均值（标准化后为零）。

- 完整性数值检查：归因总和相对目标输出差的平均绝对误差为 0.00386，约占平均输出差 6.80265 的 **0.057%**。这检查数值积分是否近似满足完整性，并不证明物理正确。
- 每个样本归因绝对值最大的 26 个频点（257 维的 10.1%）平均占其绝对归因总量 **38.0%**。不同样本的前 26 个频点可以不同。
- 将每个样本的这 26 个特征替换为基线后，准确率由 100% 降至 **94.47%**，原类别相对次高类别的平均 logit 差下降 2.868。随机遮蔽 26 个特征的 20 次平均准确率仍为 100%，平均 logit 差下降 0.124。此处遮蔽的是标准化后的 FFT 特征，不是对真实信号进行物理干预。
- 原始预测在五次独立噪声抽样中均保持不变。固定比较原始预测类别与原次高类别，20 dB AWGN 下前 26 频点集合的平均 Jaccard 相似度为 **0.828**；−4 dB 下为 **0.372**。Jaccard 取交集数量除以并集数量；后者是较强扰动下的观察，不能单独认定解释无效。重复抽样反映噪声变化，而非不同轴承。

FFT 频点之间可能相关，平均向量基线与人工遮蔽后的频谱可能脱离真实数据分布。因此这里衡量的是模型对特征的依赖，而不是频点造成故障的证据。

## 符号表达式与剪枝忠实度

当前层先计算 `tanh(x)`，再用 Chebyshev 基函数和 `coeffs * sigmoid(order_weights)` 的有效系数。原附录 `extract_symbolic.py` 使用了不同的门控变量名，并仅短训演示模型；它也没有将 `tanh` 明确纳入以原标准化输入为变量的表达式，不能直接用于解释本项目权重。

在已训练模型中，按第一层 1–5 阶有效系数绝对值总和选取一条连接：FFT 的第 147 号输入（从 0 编号）到第 20 号隐藏节点。令 `t = tanh((|FFT[147]| - 训练均值[147]) / 训练标准差[147])`，该边为：

`1.947443 t^5 + 0.074695 t^4 - 2.775215 t^3 + 0.247641 t^2 + 0.995023 t - 0.169607`

在这 470 个窗口上，这条边的公式与模型计算的最大绝对误差为 **2.83×10⁻⁷**。这只是一个内部连接的重构，不是整个分类器的公式，也不是故障机理方程；按系数大小选择连接不等于因果重要性。若故障记录采样率取 12 kHz，其对应频点约为 3445.31 Hz，不能据此声称与理论故障频率对齐。

对两层有效系数按绝对值阈值事后置零，不进行重新训练，在同一测试集上与原模型比较：

- 阈值 0.02：50,112 项中置零 **54.85%**，预测一致率 **100%**，logit 平均绝对差 0.273。
- 阈值 0.05：置零 **92.17%**，预测一致率 **99.57%**（468/470），logit 平均绝对差 0.684。
- 阈值 0.10：置零 **99.36%**，一致率降至 **26.17%**。

上述阈值是在同一测试集上做的事后敏感性分析，并非独立验证的最佳阈值；预测一致不意味着置信分数相同，也不自动带来实际运行加速。阈值、系数稀疏率、门控稀疏率和物理解释真实性不是同一指标。

## 与论文物理频率结果的关系

论文报告 BPFI、BPFO 等频率对齐，但项目目前没有完成相同物理对齐验证。CWRU 附录脚本使用 512 点实数 FFT，模型输入只有 257 个频点；论文示例 `x_614` 不在这个输入范围。对于 12 kHz 故障记录，该 FFT 频率间隔为 23.4375 Hz，论文表格中的 160、110、140 Hz 并非该设置的原始 FFT 格点，可能需要不同预处理，但论文与附录之间的对应关系尚未建立。正常记录的采样率也尚未确定。

论文正文还给出峰度、小波熵和 RMS 的经验公式；当前 CWRU 模型输入是 FFT，因此不能声称本项目已恢复该公式。论文表中的约 141 Hz 与常用公式计算的滚动体自转频率约 70.6 Hz 的两倍接近；具体使用基频还是二次谐波应注明定义。

## 运行与文件

从项目根目录在 PowerShell 运行：

```powershell
$env:PYTHONNOUSERSITE = '1'
.\.venv\Scripts\python.exe .\interpretability\symbolic\analyze.py
.\.venv\Scripts\python.exe .\interpretability\integrated_gradients\eval_ig.py
```

`symbolic/symbolic_metrics.json` 保存公式和各阈值指标；`integrated_gradients/metrics.json` 保存归因、遮蔽及五次噪声实验的参数和指标。重新运行会覆盖各自 JSON。依赖已有项目数据、CWRU 模型与 Python 环境。

建议下一步固定可解释性评价方案，在 Paderborn 的独立轴承测试集上复核归因稳定性，并在确认采样率和轴承几何后，采用适合窗口频率分辨率的频带或包络谱检验。若要选剪枝阈值，应在验证集选择，再用独立测试集报告预测及 logit 保真度。

方法参考：[Integrated Gradients 原始论文](https://proceedings.mlr.press/v70/sundararajan17a.html)；[滚动轴承故障频率计算说明](https://www.mathworks.com/help/predmaint/ug/Rolling-Element-Bearing-Fault-Diagnosis.html)。
