# XJTU-SY 三次 B 样条 KAN 可视化与对照

原论文复现和 `rul_study/` 的现有 KAN 使用 Chebyshev 多项式，不是 B 样条。本目录另外训练一个**真正基于三次 B 样条基函数**的网络：每条边为 9 个固定基函数的加权和，两层分别对输入边求和，没有声称显式稀疏正则化。

每层的每个输入先映射 `z = 3*tanh(x/3)`；其中第一层 `x` 是采用训练轴承的等权均值和方差标准化的工程特征，第二层 `x` 是隐藏变量。`z` 上使用开区间均匀节点 `[-3,-3,-3,-3,-2,-1,0,1,2,3,3,3,3]` 的三次 B 样条。有效极端输入受 `tanh` 压缩：模型对原始 `x` 的整个函数是样条与 `tanh` 的复合，而不是原始坐标下的分段三次多项式；不能把标准化输入 `|x|>3` 直接称为在样条网格外。

基函数在 800 个网格点上与 `scipy.interpolate.BSpline.design_matrix` 相比，最大误差约 **2.22×10⁻¹⁶**，基函数和为 1 的最大误差约 **2.22×10⁻¹⁶**；基础实现和导数另由独立审计检查。模型固定节点而非对测试集拟合节点。

## 如何看图

`visuals/bspline_basis_and_edge.png` 三个面板从左到右：

1. 固定节点的九个三次 B 样条基函数，横轴为映射后的 `z`；这些是基函数，不是训练后的重要性分数。
2. 一条实际训练后的边：水平 RMS 到隐藏节点 2。目标是展示边形状；先固定水平 RMS，再在**训练记录中**选择边输出标准差最大的隐藏连接，没有使用测试结果选择。横轴为数据原始单位，背景色为训练记录的 5%–95% 分位数范围，中位数为虚线。纵轴是隐藏层内部的边贡献，**不是预测寿命分钟，也不是物理定律**。横轴显示训练记录 1%–99% 分位数。
3. 水平 RMS 改变，其他全部模型输入固定为训练集均值时，完整网络的预测随之变化。输出先反标准化并裁剪非负。其他特征被固定为均值可能构造不真实的特征组合，因此这是模型条件响应而非真实干预或因果效应。阴影仅是样本覆盖范围，不是置信区间。

## 哪些特征影响现有模型

`visuals/bspline_feature_importance.png` 用积分梯度解释事先固定的 **Bearing1_3** 留出测试轴承 158 次采集，基线为该折训练特征的等权均值，积分 128 步，对反标准化、裁剪非负后的预测计算。按该轴承所有记录的**绝对归因均值**排列，前三为垂直峰值、垂直偏度、转速。它们是该模型和基线下的依赖度，不是故障原因；强相关特征、固定均值基线和积分路径会产生不真实组合。

该图中的 158 个测试记录来自同一条留出轴承轨迹，并非独立轴承。该折约 **29.7%** 原始网络输出被裁剪为 0，需同时关注这一局限。积分梯度数值完整性绝对误差均值约 **0.255 分钟**，相对平均输出差 159.64 分钟约 **0.16%**；这仅验证数值计算，不等于预测正确。`visuals/interpretability.json` 给出全部特征、训练分位数和数值验证。

## 真实留一轴承结果（单种子）

使用已有 `rul_study/results_merged/folds.json` 的同一训练/验证/测试轴承分组、相同当前记录特征、训练集等权缩放、两个隐藏宽度、最多 60 轮及早停；只能在验证轴承上选模型。15 个轴承均作为独立测试对象各一次，训练种子均为 42。B 样条 KAN 的轴承宏 MAE 为 **288.28 分钟**，宏 RMSE 为 **349.10 分钟**。原 Chebyshev KAN 在完全相同种子与分组下宏 MAE **282.59 分钟**，MLP **299.93 分钟**；均仅为单种子比较，不足以断言谁在总体上更优，两个模型的计算开销也不完全相同。不同种子、不同训练轴承和工况下的函数形状稳定性尚未验证。训练数据都包含三种工况，未验证未见工况外推。

目标为距最后一次记录的分钟数，末次采集是终点代理，不保证等同机械失效时刻。`results_seed42/folds.json` 保存所有分组、验证选型和测试指标，`results_seed42/predictions.csv` 保存逐采集预测，`results_seed42/checkpoints/` 保存每折模型与训练缩放参数。

## 复算

在项目根目录：

```powershell
$env:PYTHONNOUSERSITE='1'
.\.venv\Scripts\python.exe .\bspline_study\train.py --seed 42 --epochs 60 --patience 8 --output .\bspline_study\new_results
.\.venv\Scripts\python.exe .\bspline_study\visualize.py
.\.venv\Scripts\python.exe .\bspline_study\render_plot.py
```

默认可视化加载已保存的 `results_seed42/checkpoints/Bearing1_3_seed42.pt`；重训输出到 `new_results`，可用 `--checkpoint` 显式选择。绘图与训练分析分进程执行，避免部分 Windows 环境中 PyTorch、SciPy 或 matplotlib 的 OpenMP 运行时冲突。可视化脚本会覆盖 `visuals/` 下的对应文件。依赖项目既有 `.venv` 和 `rul_study` 数据。
