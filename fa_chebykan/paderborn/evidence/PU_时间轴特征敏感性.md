# PU 时钟处理的特征敏感性检查

对 36 条原始录音各自的前 1.2 秒进行诊断，仅比较输入处理，不评估模型或使用故障标签选参数。

本诊断直接在 64 kHz 信号上带通，而主实验先将振动信号降至 12 kHz 后再带通；因此数值仅用于检查时间处理敏感性，不能直接解释为主实验模型预测的变化。
方法 A：取前 76800 点并当作 64 kHz；方法 B：依据 MAT vibration_1 对应的 X 时间轴线性插值至 64 kHz 的前 1.2 秒。两者采用同一段实测速率均值，之后相同 1600–4800 Hz 四阶 Butterworth 零相位带通、Hilbert 包络、抗混叠重采样到 3 kHz，计算同一组 33 个几何锚定相对幅值特征。
相对 L1 差异定义为两组 log1p 特征的绝对差之和，除以插值方案特征绝对值之和。它是特征一致性指标，不是准确率、真实误差或插值正确性的证明。

按平均等效采样频率偏离 64 kHz 不超过 1% 选取的 32 条记录：相对 L1 差异中位数 0.0038，范围 0.0005–0.1193。

例子：

- N15_M07_F10_K001_1：平均等效 64000.02 Hz，特征相对 L1 差异 0.0064。
- N15_M07_F10_KI01_1：平均等效 64501.96 Hz，特征相对 L1 差异 0.0289。
- N15_M07_F10_KI05_1：平均等效 64523.55 Hz，特征相对 L1 差异 0.0037。
- N15_M07_F10_K005_1：平均等效 64000.01 Hz，特征相对 L1 差异 0.0019。

阈值只筛选平均频率，不能排除局部时间戳异常。线性插值对不均匀采样不是严格抗混叠滤波，无法证明连续信号可被无失真恢复；固定 64 kHz 与时间轴插值都是待验证假设，需关注处理敏感性。全部逐录音数值见 `timebase_feature_sensitivity.csv`。
