# 数据与训练说明

现行 CWRU 数据准备、两种采样率假设、四模型训练及少样本评估命令见 [FA_CWRU_复现说明.md](FA_CWRU_复现说明.md)。数据原始出处及未证实的元数据见 [CWRU_元数据核查.md](CWRU_元数据核查.md)，结果见 [实验结果报告](results/CWRU_实验结果报告.md)。

数据集 CSV 每行代表一个片段，`x` 为 JSON 数组，`shaft_speed` 为 Hz 标量或逐采样数组；`data.FIELDS` 定义剩余字段。数据验证要求记录级划分不能交叉、单段覆盖至少 10 个保持架周期。CWRU 的加速度单位在本次核查中未被证实，因此标为 `unknown`；不能未经证明写为 `g` 或 `m/s²`。

带通和包络处理与 PyTorch 训练分别运行，缓存记录 CSV 的 SHA-256、预处理频带和有效采样率。模拟器只生成演示性质的冲击和共振信号，尚未证明真实设备的动力学覆盖。由于幅值归一化，辅助 A0 头不能保证恢复绝对冲击幅值。

Paderborn、XJTU-SY 的故障分类标签和 CNC 主轴实测数据仍待核实、适配。XJTU-SY 的终末故障位置不能自动作为所有运行片段的分类标签。
