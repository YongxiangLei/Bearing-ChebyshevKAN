# FA-ChebyKAN 故障诊断研究原型

本目录按 `FA-ChebyKAN_Model.md` 的研究方向准备，与原有的 XJTU-SY 剩余寿命预测工作独立。它包含物理阶次锚定模型、示例仿真生成器、录音级数据接口、CWRU 初步实验及英文研究方案；目前不是经充分验证的诊断系统，也不是可投稿的结果论文。

## 内容

- `core/model.py`：轴承特征阶次、可学习滑移、故障谐波与边带投影、Chebyshev KAN 分类器及仿真辅助回归头。
- `core/signal.py`：带通和 Hilbert 包络。可用固定频带或峰度启发式选带；后者不是 Fast Kurtogram。
- `data.py`、`simulator.py`：CSV 数据接口、仿真示例生成及需明确提供已核实元数据的 CWRU 导入器。
- `preprocess.py`、`experiment.py`：离线包络缓存、仿真预训练和录音级零样本及少样本评估流程。
- `DATA_TRAINING.md`：本机运行命令、数据字段、实验约束和未完成事项。
- `manuscript/`：英文 MSSP 定向研究与方法初稿、中文执行和投稿前清单。
- `tests/`：数学、数据接口和独立录音划分的自动检查。

## 已验证的范围

已用模拟信号预训练，在 CWRU 上按录音划分测试零样本、每类 K=1 和 K=2 录音微调，并与三个基线比较。每种情景的测试集仅四条录音，且不同录音可能来自同一轴承；结果与采样率假设详见 [实验结果报告](results/CWRU_实验结果报告.md)，复现命令见 [复现说明](FA_CWRU_复现说明.md)。这不是工业验证或跨轴承泛化证据。

目前没有合作方仿真数据或 CNC 主轴实测数据。CWRU 正常记录采样率、信号单位和部分轴承几何仍有明确标注的假设；Paderborn、XJTU-SY 诊断标签及 CNC 数据适配尚未完成。XJTU-SY 的终末故障标签不能直接赋给全寿命的每个片段。更多种子、强基线、消融和外部测试也仍待完成。

投影的谐波和边带是候选故障特征，并非经过校准的故障概率或严格能量占比；中心频率 `m=0` 只计一次。输入按包络幅值归一化，仿真辅助头不能保证唯一恢复绝对冲击幅值 A0。正式论文中须依据实验结果重新检验方法、可解释性与机械贡献。
